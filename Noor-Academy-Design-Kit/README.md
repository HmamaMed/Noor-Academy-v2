# Noor Academy - UI / UX Design Kit

Design concept 01: **Light, with purpose.**

Prepared from the attached `NOOR_ACADEMY_DESIGN_BRIEF.md`, 5 October 2026.

## Start here

- `Noor-Academy-Design-Book.pdf`: visual direction, screen boards, exact design properties, page specifications, states and handoff checklist.
- `Noor-Academy-UI-Specification.md`: editable written specification covering all 16 routes.
- `noor-tokens.css` and `noor-tokens.json`: centralized design values. These are design handoff assets, not a working application.
- `screens`: original generated UI concept boards at their supplied resolution.
- `image-prompts.json`: the prompts used with the built-in image generation tool.
- `contrast-checks.json`: calculated sRGB contrast for the specified solid-color pairs.

## Status of the work

These are static high-fidelity design concepts, not functioning authentication, enrollment, publishing, or downloads. The written specification and tokens are authoritative for implementation. Image generation can approximate typography, labels, dates, borders and spacing; do not extract production text or exact measurements from raster boards. Use the canonical demonstration data and route inventory in the specification.

The design uses existing workflows: scheduled groups, manual enrollment confirmation, a 72-hour pending window, and lessons/exercises/corrections. A pending application does not guarantee a seat. Confirmed students retain materials access for completed groups.

All illustrated courses, teacher identifiers, student identifiers, room identifiers, schedules and availability are demonstration content. No real staff, premises, outcomes or qualifications are represented. The proposed logo and abstract course motifs are new design concepts, not existing approved assets or new database fields.

English is the design baseline. Arabic, French, a parent role, online checkout, grading, submissions, chat, video teaching and progress analytics are outside this concept.

The product fonts are Lora and Inter. Generated typography is illustrative; the PDF's written pages use embedded local substitute fonts for reliable offline viewing. Production should use the exact specified fonts after obtaining their official font files and license notices.
